# MoodBeats User Flow

## Flow 1: First-Time User
1. Land on Login Page → See warm amber branding, gradient background
2. Click "Create one" → Signup Page
3. Fill form → Submit → Redirect to Login
4. Login → Dashboard (Discover tab)

## Flow 2: Discover Music (Core Loop)
1. Dashboard → Discover tab (default)
2. See hero search card with amber glow
3. Type vibe OR click suggestion pill
4. Loading spinner → Playlist appears
5. Section 1: Library matches with play buttons
6. Section 2: AI Recommendations with save buttons
7. Click play → Bottom player appears
8. Toggle 30s/Full mode
9. Click save → Song added to library

## Flow 3: Build Library
1. Switch to Library tab
2. See filter bar: search + mood pills
3. Browse song cards with metrics (BPM, energy, danceability)
4. Play/delete songs
5. Filter by mood to organize

## Flow 4: Import Songs
1. Switch to Search & Import tab
2. Choose Artist Discography OR Track Search
3. Search → Results grid
4. Preview → Add to library
5. Or paste Spotify URL → Import directly

## Flow 5: View Analytics
1. Switch to Analytics tab
2. See stat cards: Total Songs, Avg Tempo, Avg Energy
3. See mood distribution donut chart
4. Color-coded mood segments

## Navigation Pattern
- Sticky header with gradient logo
- Floating pill tab bar (Discover | Library | Search | Analytics)
- Bottom player (appears when track playing)
- Page transitions with fade animations
